# API

Contract: `docs/openapi.yaml` (OpenAPI 3.1). REST under `/v1`, JSON, zod-validated, errors `{ message, issues[] }`.
Typed client `@worko/api-client` is generated from it (`pnpm --filter @worko/api-client generate`); CI fails if it is stale, and `apps/api/test/contract.int.test.ts` fails if routes and spec differ.

## Conventions
- Auth: `Authorization: Bearer <access>`; refresh via `POST /auth/refresh` (rotation, reuse detection kills the family).
- Idempotency: all POST/PATCH will accept `Idempotency-Key` (table exists; middleware lands with the first business mutations in Phase 2/3).
- Pagination: cursor-based `?after=&limit=`. Filtering via saved-view definitions, never raw SQL.
- Sync: `POST /sync/push`, `GET /sync/pull?since=`; WS `/v1/realtime` emits `{type:'changed', cursor}` hints.
- Public API: per-firm API keys with scopes + rate limits; webhooks signed with HMAC-SHA256.

Errors are `{ statusCode, message, code?, issues? }`. Task rule codes (400): `udin_required` (audit task without UDIN, D116), `required_checks_pending`, `reviewer_required`, `pending_issue_required`, `act_by_after_due`, `task_closed`, `task_not_done`, `person_cannot_see_task:<field>`. Time/HR codes: 409 `timer_running`, `immutable`, `already_reversed`, `already_checked_in`, `leave_overlap`, `insufficient_balance`, `not_pending`, `already_billed`, `amount_mismatch`; 400 `future_date`, `client_mismatch`, `day_over_24h`, `over_limit`, `leave_type_not_applicable`; 403 `self_approval`, `cost_hidden`. Communication codes: 409 `template_in_use`, 403 `account_mismatch`, 400 `template_required_for_category`, `address_not_on_client`, 409 `opted_out`, `not_opted_in`, `over_cap`, `template_required`, `template_not_approved`, `no_address`, `provider_decides`, `no_recipients`, `slot_unavailable`, `not_changeable`, `oauth_failed`, `direct_fixed`; 400 `invalid_template` (issues), `missing_variables`, `bad_variables`, `edit_window_closed`, `member_cannot_view_client`, `too_long`, `invalid:mentions`, `invalid:attachment_doc_ids`; 403 `self_approval`. Portal/leads codes: 409 `invoice_not_open`, `no_contact`, `identity_conflict`, `portal_user_disabled`, `already_decided`, `superseded`, `expired`, `withdrawn`, `not_sent`, `proposal_closed`, `not_accepted`, `duplicate_client` (candidates + hidden count), `lead_converted`, `lead_closed`; 400 `empty_response`, `no_rate`, `lost_reason_required`, `lead_won_final`, `invalid_transition`, `convert_to_win`, `invalid:neighbour`, `entity_type_required`, `not_client_document`; 429 portal OTP lockout. Bearer tokens only (no cookies), so CSRF does not apply; portal and staff tokens differ in issuer + audience. Automation/AI codes: 400 `invalid_rule` (issues), `personal_rule_action`, `invalid_params`; 409 `not_paused`, `already_decided`, `expired`, `nothing_to_summarise`; 403 `no_ai_mode`, `ai_disabled`, `feature_disabled`, `ai_cap`, `redaction_failed`. Run-action codes (recorded, not HTTP): `refused` (business rule: `opted_out`, `udin_required`, `cost_cap`, `no_recipient`…), `queued` (quiet hours), `rate_limited`, `needs_approval`; run skip reasons `self_trigger`, `depth_limit`, `outside_owner_scope`, `automation_off`, `entity_gone`. Special codes: `MFA_REQUIRED`, `DEVICE_WIPE`, `STEP_UP_REQUIRED`, `PASSWORD_REQUIRED` (share links). Invisible records return 404 (never 403) so existence isn't confirmed.
