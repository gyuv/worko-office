# Glossary

| Term | Meaning in Worko |
|---|---|
| AY / FY / Tax Year | Assessment year / financial year (April–March, written 2026-27). From FY 2026-27 the Income-tax Act 2025 uses "tax year"; Worko labels both. |
| Act-by date | The date to act by when a statutory due date falls on a holiday and the law allows shifting. |
| Article / articled assistant | CA trainee under a member's supervision; has article-specific leave (study/exam). |
| CGST / SGST / IGST | Central/State GST for intra-state supply; Integrated GST for inter-state supply (decided by place of supply). |
| DIN | Director Identification Number (MCA). |
| DLT | TRAI's Distributed Ledger registration required for commercial SMS templates and sender IDs. |
| DPDP Act | Digital Personal Data Protection Act, 2023 — consent, rights requests, breach duties. |
| DSC | Digital Signature Certificate (USB token) used to sign returns and filings; tracked in the DSC register. |
| E-sign | Aadhaar-based electronic signature through a licensed e-sign service provider (ASP/ESP). |
| GSTIN | 15-character GST registration number: state code + PAN + entity no. + `Z` + check character. |
| GSTR-1 / GSTR-3B | Outward-supplies return / monthly summary return with tax payment. QRMP = quarterly filing with monthly payment. |
| ICAI | Institute of Chartered Accountants of India (issues UDINs). ICSI: Institute of Company Secretaries of India. |
| ITR | Income-tax return. |
| Late fee / interest | Statutory charges for delay; Worko's calculators are indicative, not advice. |
| MCA / ROC | Ministry of Corporate Affairs / Registrar of Companies (AOC-4, MGT-7, DIR-3 KYC filings). |
| PAN / TAN | Permanent Account Number / Tax deduction Account Number. |
| PBC list | "Prepared by client" — the documents a client must provide for an audit. |
| Place of supply | Where a service is deemed supplied; decides CGST+SGST vs IGST. |
| SAC | Services Accounting Code on invoices (professional services: 998231 etc.). |
| TDS (194J etc.) | Tax deducted at source by a client from your fee; recorded on the receipt. |
| Tally | Tally ERP/Prime accounting software; Worko exports vouchers as Tally XML. |
| UDIN | Unique Document Identification Number generated on the ICAI portal for certificates/reports a member signs. Worko records and validates the format; it never generates UDINs. |
| WIP | Work in progress — unbilled work valued at fee or cost. |
