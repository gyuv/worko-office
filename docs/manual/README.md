# Worko user manual

Worko runs your CA/CS practice: every piece of work is created once, has an owner and a due date, moves through stages,
gets billed and collected — and nothing is forgotten. It works in a browser, as a Windows/macOS/Linux desktop app
(keeps working offline, reminders from the tray) and on Android (offline, attendance check-in, document scanning).
Your clients use the **client portal** in their browser.

Conventions: money is shown in rupees with Indian grouping (₹1,23,456); dates and times are India time (IST); the
financial year runs April–March (FY 2026-27). Menu paths are written **Settings → Rates**.

What Worko does **not** do: it never files returns or scrapes government portals for you, never generates UDINs
(it records them and links to the ICAI portal), and never sends anything written by AI without a person approving it.
